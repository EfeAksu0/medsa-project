> **Medysa** is a production AI-powered trading journal and forensic analytics SaaS built for active financial market traders. It automatically analyzes trade executions, detects emotional tilt (FOMO, revenge trading), computes key portfolio statistics, and provides personalized AI coaching.

---

## 🌟 Key Features & Highlights

* 🤖 **AI Trading Psychologist**: Integrates Google Gemini API with custom prompt engineering to run forensic autopsies on trade logs, identifying psychological biases and discipline breaches.
* 📊 **Institutional Analytics Engine**: Computes real-time performance metrics including win rates, profit factors, drawdown curves, and asset-class distribution using Prisma ORM & PostgreSQL.
* 💳 **Monetized SaaS Architecture**: Integrated with Stripe API for subscription tier handling, webhooks, and secure user account management.
* 🎨 **High-Performance UI/UX**: Built with Next.js 14, React, Tailwind CSS, custom animations, and responsive dark-mode aesthetics.
* 🎬 **Automated Social Marketing Module**: Includes an internal "Reel Creator" tool to automate social media visual asset generation for user acquisition.

---

## 🛠️ Technical Stack

* **Frontend**: Next.js 14 (App Router), React, TypeScript, Tailwind CSS, Lucide Icons, Framer Motion
* **Backend**: Node.js, TypeScript, RESTful API Routes
* **Database & ORM**: PostgreSQL, Prisma ORM
* **AI Integration**: Google Gemini API (Structured Prompt Pipelines & Contextual Analysis)
* **Payments & Auth**: Stripe API (Subscriptions & Webhooks), NextAuth / Custom Auth
* **Infrastructure**: Vercel Serverless Functions, Git / GitHub
